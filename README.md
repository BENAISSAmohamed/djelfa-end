# منصة ملحقة المدرسة العليا للأساتذة - الجلفة

بوابة جامعية مبنية باستخدام React + Vite + Supabase، بثلاث لغات (العربية والفرنسية والإنجليزية)، وتصميم عنابي/ذهبي ومتوافق مع الهواتف.

## الوظائف الحالية
- واجهة رئيسية وإعلانات منشورة.
- قائمة تخصصات حسب أطوار التعليم.
- تسجيل حساب طالب وتسجيل الدخول والخروج عبر Supabase Auth.
- ملف شخصي وبطاقة طالب مبسطة.
- مكتبة موارد قابلة للبحث.
- نشر موارد تعليمية للمعلمين والمسؤولين فقط.
- نشر الإعلانات وحذفها من حساب المسؤول فقط.
- قاعدة بيانات وسياسات RLS وStorage مرفقة في `supabase/schema.sql`.

## متطلبات التشغيل
- Node.js إصدار 20 أو أحدث (يوصى بـ LTS).
- حساب Supabase ومشروع جديد.
- Git وGitHub اختياريان للنشر.

## 1. إعداد Supabase
1. أنشئ مشروعًا جديدًا من https://supabase.com.
2. افتح SQL Editor في لوحة Supabase.
3. الصق محتويات `supabase/schema.sql` كاملة وشغّلها.
4. من Project Settings > API (أو قسم Connect حسب واجهة Supabase) انسخ Project URL والمفتاح العام publishable/anon.
5. لا تستخدم `service_role` أو أي مفتاح سري داخل تطبيق المتصفح.

## 2. إعداد المشروع محليًا
1. فك ضغط المشروع.
2. انسخ `.env.example` إلى `.env.local`.
3. ضع القيم الصحيحة:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY
```

4. افتح الطرفية داخل مجلد المشروع وشغّل:

```bash
npm install
npm run dev
```

5. افتح الرابط المحلي الذي يظهر في الطرفية، غالبًا `http://localhost:5173`.

بعد تغيير `.env.local` أوقف خادم التطوير وأعد تشغيل `npm run dev`.

## 3. إنشاء حساب المسؤول الأول
1. شغّل الموقع وسجّل حسابًا بالبريد الذي تريد تخصيصه للمسؤول.
2. افتح لوحة Supabase > SQL Editor.
3. نفّذ الاستعلام التالي مع استبدال البريد ببريد المسؤول الحقيقي:

```sql
update public.profiles
set role = 'admin'
where email = 'YOUR_ADMIN_EMAIL';
```

4. سجّل الخروج ثم الدخول مجددًا. إذا كان الحساب مسجلًا الدخول أثناء تغيير الدور، أعد تحميل الصفحة.
5. لا تجعل التسجيل العام يتيح اختيار دور المسؤول أو الأستاذ. أدوار الحسابات الجديدة تُنشأ كطلاب افتراضيًا.

لترقية أستاذ، ينفذ المسؤول المصرح له تغيير الدور من لوحة قاعدة البيانات بعد التحقق من هوية الحساب. لا تضع أي مفتاح `service_role` في الواجهة.

## 4. إعداد مصادقة البريد
من Supabase > Authentication > URL Configuration:
- أضف عنوان الموقع المحلي أثناء التطوير، مثل `http://localhost:5173`.
- عند النشر أضف نطاق الموقع النهائي إلى Site URL وRedirect URLs.
- اضبط إعدادات تأكيد البريد وفق سياسة المؤسسة.
- استخدم كلمات مرور قوية وفعّل وسائل الحماية المتاحة في مشروع Supabase.

## 5. النشر على GitHub وVercel
1. أنشئ مستودع GitHub وارفع ملفات المشروع دون `.env.local`.
2. افتح https://vercel.com واختر Add New Project ثم استورد المستودع.
3. اجعل Framework Preset هو Vite (عادة يُكتشف تلقائيًا).
4. أضف Environment Variables:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. انشر المشروع.
6. أضف نطاق Vercel إلى Supabase Authentication > URL Configuration.
7. اختبر التسجيل والدخول والأدوار ورفع الملفات من هاتفك.

بديل: يمكن نشر المشروع على Netlify بنفس متغيرات البيئة، وأمر البناء `npm run build` ومجلد الناتج `dist`.

## 6. التخصصات المدرجة
- مسار علوم: علوم الطبيعة والحياة، الرياضيات، الفيزياء، الإعلام الآلي.
- أستاذ التعليم الابتدائي: اللغة العربية، اللغة الفرنسية.
- أستاذ التعليم المتوسط: اللغة العربية، اللغة الفرنسية، اللغة الإنجليزية، التاريخ والجغرافيا، الإعلام الآلي، التربية البدنية، علوم الطبيعة والحياة.
- أستاذ التعليم الثانوي: التربية البدنية.

تظهر تخصصات العلوم العامة أيضًا في قائمة الموارد. راجع المسؤولية المؤسسية للتأكد من مطابقة القائمة النهائية للتخصصات المعتمدة رسميًا.

## تنبيهات أمان وحدود النسخة
- RLS مفعّل في الجداول الأساسية، وملفات الموارد محفوظة في bucket خاص.
- لا تضع أسرار Supabase أو كلمات مرور في الكود أو GitHub.
- هذه نسخة أساس قابلة للتشغيل وليست اعتمادًا أمنيًا نهائيًا لمؤسسة. اختبر السياسات بحسابات طالب وأستاذ ومسؤول منفصلة قبل نشر بيانات حقيقية.
- بطاقة الطالب المعروضة واجهة تعريفية وليست وثيقة رسمية، ولا يوجد حاليًا تحقق QR أو تكامل مع نظام تسجيل جامعي.
- لا تتضمن النسخة الحالية إدارة كاملة للمستخدمين من الواجهة أو تسجيل حضور وغياب فعليًا؛ يمكن إضافتهما في مرحلة تالية مع جداول وسياسات واختبارات خاصة.
- لا تُدخل بيانات شخصية حقيقية قبل مراجعة سياسة الخصوصية والاحتفاظ بالبيانات.


## الإضافات في النسخة المحدّثة

- **فضاء الطالب:** بطاقة رقمية بتصميم جامعي، مع ملخص الحضور والغياب والتأخر وسجل الحصص طوال العام. تظهر السجلات بعد حفظ الأستاذ للحصة.
- **فضاء الأستاذ:** اختيار عنوان الحصة والتاريخ والتخصص والفوج، وتعيين حالة كل طالب (حاضر/غائب/متأخر). بعد الحفظ تظهر رسالة بعدد الغائبين والحاضرين.
- **المكتبة:** نشر درس أو ملخص بنص مكتوب مباشرة، مع خيار إرفاق ملف PDF أو Word؛ الدروس النصية تظهر للمطالعة دون تنزيل ملف.
- **الإعلانات:** أحدث إعلان يظهر أولاً حسب تاريخ النشر.
- **الوضع الليلي:** زر القمر/الشمس في الشريط العلوي، ويحفظ الاختيار محلياً.
- **المواد حسب التخصص والطور:** أُضيفت قوائم إرشادية للمواد المدرسية التي يدرّسها خريجو التخصصات. ليست هذه القوائم بديلاً عن قائمة مقاييس التكوين الجامعي المعتمدة؛ ينبغي مراجعتها وتحديثها وفق المناشير الرسمية. ترتيبات وزارة التربية الوطنية للموسم 2026–2027 تشير إلى تدريس الإنجليزية ابتداءً من السنة الثالثة ابتدائي والفرنسية ابتداءً من الرابعة. راجع الموقع الرسمي: https://www.education.gov.dz/2026/07/25/وزير-التربية-الوطنية-يشرف-على-أشغال-الندوة-الوطنية-لتحضير-الدخول-المدرسي-2026-2027-ويعلن-عن-إصلاحات-جديدة-لتعزيز-جودة-التعليم/

## إعداد قاعدة البيانات

إذا كنت قد شغّلت ملف `supabase/schema.sql` في نسخة سابقة، شغّله مرة أخرى من SQL Editor لتطبيق الجداول والسياسات الجديدة وإضافة عمود محتوى الدرس. أو نفّذ على الأقل أوامر الترحيل الموجودة في نهاية الملف. لا تضع مفتاح `service_role` في الموقع أو في GitHub.

## ملاحظة مهمة حول الحضور

حتى تظهر أسماء الطلبة في قائمة الأستاذ، يجب أن تكون صلاحية الحساب `teacher` أو `admin` وأن يكون تخصص الطالب مطابقاً للتخصص المختار. إنشاء حساب عام لا يمنح صاحبه صلاحية الأستاذ؛ يعيّن المسؤول الصلاحيات من Supabase بعد التحقق من الهوية.
